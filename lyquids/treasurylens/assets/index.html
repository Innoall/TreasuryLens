WHAT THIS MODEL CAN & CANNOT SHOW

Agreement has a scope.

Value-only voting can accept identical numbers from different snapshots. Binding the query, snapshot, count and log digest makes the agreement more specific. It still cannot detect a shared faulty data source or a sufficiently dishonest committee.

The deployed application additionally uses authenticated node identities and Lyquor’s certified-call protocol. This model demonstrates a simplified policy; it does not simulate cryptographic signatures, network timing or the full runtime.

TRUST & SCOPE

Know what each layer tells you.

01

Committee certification

A configured threshold approved the exact shared-state update. Supporters and certifiers may differ. The setup authority and enough honest nodes remain assumptions.

02

Source replay

A new read from the source RPC reproduced the stored summary. It can expose discrepancies, but a shared or dishonest RPC can still return a shared error.

03

Portable evidence

Imported logs can be recomputed against the supplied query and summary. A valid content check does not verify a committee certificate or canonical chain membership.

04

History semantics

Gross outgoing standard ERC-20 Transfer events, including self and zero-value transfers. This is neither net accounting nor a fraud assessment. No real assets move.
