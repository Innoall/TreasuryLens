# 组外真实试用记录表

这是一份尚未填写的测试协议，不代表已经发生的用户反馈。不要把自动化测试或 AI 角色扮演当作真实组外用户。

## 给试用者的任务

1. 从 README 启动应用，或由开发者提供已运行的本机页面；记录属于哪种情况。
2. 使用默认数据发起查询，说出显示的是总转出还是净支出。
3. 找到支持观察的节点与证书签名节点，说出它们的区别。
4. 重放源数据，筛选一名收款人，并核对总额与逐笔记录。
5. 导出证据文件，再导入；解释“内容有效”为什么不是“证书已验签”。
6. 检查当前快照，指出其来源以及最终性限制。
7. 比较默认区间与空区间，检查区间重叠提示和预算等值边界。
8. 在 Integrity Lab 中配置两个过期快照节点，观察只比较数值的规则和绑定快照规则的不同。
9. 用窄屏或手机窗口、键盘 Tab/Enter/Escape 操作导航、对话框、筛选与导出。

## 验收原则

记录观察到的行为，不暗示试用者必须给好评。遇到失败先保留证据，再修复并复测。提交课程报告时只引用确实完成的用户测试结果。
