# Chrome 按钮检查记录

日期：2026-11-13（Asia/Hong_Kong）。对象：本机 `http://127.0.0.1:8080/`，通过 Chrome 原生窗口实际点击与读取页面状态。

## 重点按钮的实际行为

`Latest mature block` 每次请求新的源链状态，将起止区块都设为 `head − confirmations`。它选择**一个**满足深度要求的区块。例如源链高度从 22 增至 23 后，再次点击会将区间从 `20–20` 改为 `21–21`。这个按钮不会提交查询，也不会自动查询整个历史。单个成熟区块可能没有转账，结果为零仍是有效结果。

`Use seeded interval` 恢复造数时的 treasury、token、`6–10` 区间及预算。该区间包含 3 笔匹配转账，合计 7,500,000 个最小单位，可用于首次检查。

## 已修复并复测

- Latest 原来只读取页面缓存且无就近反馈；现每次重新读取链头，在弹窗内显示填入区间、源高度及后继块要求。
- 读取中禁用两个预设按钮和提交按钮，防止重复操作；超时保留原区间。Chrome 中暂停项目代理模拟了超时，确认显示错误、保留 `6–10`、禁用提交，再通过 Retry connection 恢复。
- 预设恢复会清除被替换输入的过时验证状态；先输入反向区间再恢复预设，错误提示消失且范围正确。
- 普通 toast 以前会落在模态弹窗背后；现 Copy 等提示显示在当前弹窗内。Chrome 实测 Transfer detail → Copy 后显示 `Copied`。
- 网络错误清除旧连接状态，显示 Unavailable；未成熟区块等业务错误不误报断线。
- 未来区块原先提前请求不存在的区块头，报出 `invalid RPC quantity`；现先检查区块深度，明确返回需要两个后继块及当前源高度。Chrome 用 `9999–9999` 实测，恢复种子区间后能再次成功查询。
- 实验室选择节点状态后保留键盘焦点；Chrome 实测修改节点 1 后焦点仍在节点 1，再按 Tab 到达节点 2。
