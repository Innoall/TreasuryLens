# 项目验收边界

## 可自动验收的项目内容

- 本机四节点 Lyquor 原生网络与本地 ERC-20 测试链。
- 真实转账造数、确定性标准答案、严格事件解析、去重与整数统计。
- 查询身份与终点快照绑定、完整摘要的 3/4 匹配、委员会认证后共享状态保存。
- 原始摘要的真实来源数据重放、逐笔/收款人/区块分布、金额与摘要对账。
- 当前终点哈希复查与内容证据包导出/导入、原生离线重算。
- 独立 Budget Monitor Lyquid 通过真实网络调用读取已确认来源记录。
- 正式/测试构建分离；应用层错误、过期和读取失败的故障注入。
- 交互式网页、精确浏览器预算、历史查询比较、模拟规则实验、本机查询预设。
- 启动、复现、自动检查、来源归属、安全假设和 AI 使用记录。

运行 `bash scripts/check-release.sh` 验证已运行的正式版本。故障检查使用独立测试 manifest，具体步骤见 README。来源包可由 `python3 scripts/package.py` 生成；它不包含下载工具、运行数据库或个人环境文件。

## 不能由自动化代替或推断完成的事项

1. 组外用户实际运行和反馈。只能填写真实试用情况。
2. 学生对代码、机制与结论的理解及实际分工确认。
3. 浏览器真实视觉、键盘和窄屏交互验收。2026-11-13 已在桌面 Chrome 实测主要按钮、查询恢复、弹窗反馈和实验室键盘焦点，见 [按钮检查记录](BUTTON_CHECK.zh-CN.md)；桌面及 390px 的四类统计图已目视检查并修正，见 [统计图检查记录](CHART_CHECK.zh-CN.md)。完整移动交互、文件导入选择器及清除已有个人设置的浏览器检查仍未完成。
4. GitHub 公开仓库的归属与最终上传。源码已准备好，不自动创建或发布到未指定账号。
5. 论文级新颖性判断。项目有明确机制与证据，但“首创”需要系统文献检索，不能仅从实现推断。

## 明确不纳入本次实现的内容

按用户范围，不制作 Demo 视频、PPT、pre 或课堂展示。最终课程论文式报告也没有在代码仓库中假装完成；这里的技术文档和实验记录可用于后续撰写。

## 运行限制

当前仅支持本地链31337、标准形状 ERC-20 日志和最多10,000个区块/10,000条日志。已确认查询最多保留200条。数据来源仍共享一个 RPC；两块深度不是强最终性；未实现收据根证明、独立证书离线验签、自动撤销旧快照记录和物理网络分区的硬超时保证。详见 SECURITY。
